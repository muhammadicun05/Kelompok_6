Tips untuk Vibe Code:
1. **Playwright CLI**: ini bakal kasih AI nya kemampuan untuk buka browser dan nge-tes semua tombol atau form di aplikasi kalian. jadi aplikasi kalian bisa cepet di ship tanpa habisin 5 jam testing manual
2. **Supabase plugin**:
ini bakal bantu nge-build database yang cocok untuk aplikasi kalian, jadi kalian ga perlu buang uang hiring backend developer
3. **Strix**:
Ini bakal serang aplikasi vibe code kalian persis kayak hacker beneran. jadi kalian bisa tenang, ga ada celah keamanan yang bikin data kalian bocor
4. **Skill UI for Front-End**:
tinggal kasih site referensi yang kalian suka, lalu dia bakal reverse engineer seluruh desain visual nya ke markdown file. jadi AI kalian bisa bikin persis dengan gaya yang sama, tanpa kalian jelasin panjang
5. **Context7**:
Ngasih asisten AI kalian versi paling update dari tools & library coding, biar AI gak pernah pake kodingan jadul yang bikin aplikasi error
